# 佳豪 · 黑客帝国装逼终端 💚

一打开就全屏播放炫酷音效 + 代码矩阵雨 + 假 PowerShell 终端疯狂刷代码的装逼小玩具。

同一个效果做了**两个互不依赖的版本**，各自是独立项目：

| 版本 | 目录 | 说明 |
|---|---|---|
| ✅ **原生 exe（推荐）** | [`exe/`](exe/) | 双击即全屏，**不依赖任何浏览器**。单文件 36 KB，Windows 10/11 开箱即用 |
| 🌐 **网页版** | [`web/`](web/) | 用 Chrome/Edge 的 kiosk 全屏打开。单文件 HTML，方便改、方便分享 |

## 快速开始

**exe 版**（推荐）：

```
双击 exe\JiahaoBreach.exe
```

**网页版**：

```
双击 web\start.bat
```

## 效果

1. **引导屏** — `JIAHAO-NET SECURE BOOT` 逐字打出，检测到操作者「佳豪」
2. **闪光 + 音效** — 警报三连 → 电流 whoosh → 低音爆炸 → 上行琶音（**全程只响这一次**）
3. **代码矩阵铺开** — 全屏片假名雨 + 发光拖尾 + 扫描光带 + CRT 扫描线 + 暗角
4. **假 PowerShell 弹出** — Win11 Terminal 风格，逐字敲命令，侧栏 CPU/内存/网络条实时跳动
5. **六阶段入侵** — 生物特征 → 提权 → 破防火墙 → 建隧道 → 拖库 → 擦痕迹
6. **ACCESS GRANTED** — 故障色闪 + 色差大字 + 屏幕抖动
7. **无限疯狂滚动** — 满屏假代码飞速刷过，偶尔弹出「入侵报告」

## 两个版本的区别

| | exe 版 | 网页版 |
|---|---|---|
| 依赖 | 无（仅 Windows 自带 .NET Framework 4.x） | Chrome 或 Edge |
| 启动 | 双击 exe | 双击 `start.bat` |
| 音效 | 自己合成 PCM 写进内存播放 | Web Audio 实时合成 |
| 画面 | GDI+ 自绘 | Canvas 2D |
| 全屏 | 原生无边框置顶窗口 | 浏览器 kiosk 模式 |
| 改起来 | 改 C# 重编译 | 改 HTML 刷新即可 |

两个版本的内容（台词、阶段、滚动代码）保持一致，只是实现技术不同。

## 注意

- 两个版本都是**纯本地动画**：不联网、不写注册表、不碰系统文件，放心点。
- exe 若被杀软误报（无签名的小 exe 常见），加信任即可，或改用网页版。
- 内容纯属演出效果，别当真，也别在真懂行的人面前开 😄
