# 嘉豪 · 黑客帝国装逼终端 —— 网页版

**双击 `start.bat`** 即可。自动用 Chrome/Edge 以 kiosk 全屏模式打开 `index.html`，音效自动播放。

- 单文件 HTML，零依赖、零构建，双击就能跑
- 纯本地：不联网、不写注册表、不碰系统文件
- 想改内容直接编辑 `index.html` 刷新即可，不用编译

## 快捷键

| 按键 | 作用 |
|---|---|
| `空格` | 立刻灌一大批代码，滚动更疯 |
| `R` | 重播一遍 |
| `H` | 隐藏界面，只看代码雨 |
| `ESC` | 退出全屏 |
| `Alt + F4` | 关闭窗口 |

## 目录结构

```
web/
├─ index.html    全部内容：画面 + 音效 + 终端，单文件
└─ start.bat     一键全屏启动器
```

## 启动器做了什么

`start.bat` 会自动找到 Chrome 或 Edge，带上这些参数启动：

| 参数 | 作用 |
|---|---|
| `--kiosk` | 真全屏，无地址栏无边框 |
| `--autoplay-policy=no-user-gesture-required` | **关键**：允许"不点就出声"，少了它音效会被静默拦掉 |
| `--user-data-dir=<临时目录>` | 用独立临时配置，**你已开着的 Chrome 不会抢走全屏**，也不污染你的浏览器配置 |

没找到 Chrome/Edge 时会退回默认浏览器（窗口模式，手动按 `F11` 全屏）。

> 启动器是 **CRLF 行尾 + 纯 ASCII** 的。`.bat` 用 LF 行尾时 `cmd.exe` 会在括号块里解析错乱，
> 所以别把它转成 LF，也别往里面塞中文。

## 想改内容

全部逻辑都在 `index.html` 底部的 `<script>` 里，改完刷新即可。

| 想改什么 | 找哪里 |
|---|---|
| 名字 / 主机名 | `JiaHao`、`JiaHao-PC`、`JiaHao\administrator` |
| 大字标题 | `push('<span class="big">JiaHao</span>...')` |
| 终端里滚的假代码 | `const FAKE = [...]` 数组，随便加 |
| 六阶段台词 | `const PHASES = [...]` |
| 结尾报告 | `const ENDING = [...]` |
| 滚动速度 | `await sleep(ri(30, 110))`，调小更快 |
| 雨滴密度 / 速度 | `FONT = 17`（调小更密）、`speeds` 里的 `0.35, 1.15` |
| 顶部跑马灯文字 | `const HEAD = "..."` |
| 配色 | 全局搜 `#39ff9e` / `#00ff88` 换成别的色（比如青色 `#22d3ee`） |

## 音效说明

**只有开场那一次音效**（警报三连 → 电流 whoosh → 低音爆炸 → 上行琶音），
之后全程静音，没有任何循环或重复音效。

音效由 Web Audio 实时合成，零素材文件。想加回打字声之类的，
参考 `audio()` / `tone()` / `noise()` 的用法，在打字处调用即可。
